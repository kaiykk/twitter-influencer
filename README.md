# 账号画像 · Cell 细胞 @cellinlab

一份基于 **10,018 条推文**（2019 年至今，含原创 / 引用 / 回复 / 转推）的内容创作者账号分析报告。

打开报告：**https://kaiykk.github.io/twitter-influencer/**

## 核心结论

他不是靠「发内容」做起来的，是靠**对话**：

- **62%** 的帖子是回复，独立原创只占 16%
- 回复的互动中位数是 **0 赞 / 126 浏览**——这些是社交动作，不是内容动作
- 真正的内容资产靠 **1,278 条引用 + 763 次引用自己**串成线程
- 选题极其收敛：独立开发、一人公司、小而美、个人品牌
- **29%** 的外链指向自有资产（官网 125、播客 50、公众号 28）——账号是入口，不是终点
